# Лабораторна робота №5: Моделювання руху кулі похилою поверхнею з перешкодами

**Варіант № 23**   
**Стек:** C++17, SFML 3, CMake, vcpkg  

## Опис проєкту

Програма реалізує візуальну графічну симуляцію руху кулі похилою плоскою поверхнею під дією сили тяжіння, сили тертя ковзання та з урахуванням зіткнень із нерухомими круглими перешкодами.

### Основні можливості:
- **Фізична модель:** розрахунок прискорення, сили тертя скольження та неідеально пружного зіткнення з перешкодами.
- **Траєкторія руху:** відображення історії переміщення кулі у реальному часі.
- **Динамічне керування:** зміна кута нахилу поверхні та коефіцієнта тертя під час виконання програми.
- **Зміна сценаріїв:** можливість перемикання між різними схемами розташування перешкод.
- **Інтерфейс:** вивід поточних параметрів (швидкість, кут, коефіцієнт тертя, стан симуляції) на екран.

---

## Керування

| Клавіша | Дія |
| :--- | :--- |
| `P` | Пауза / Запуск симуляції |
| `R` | Перезапуск (скидання кулі у початковий стан) |
| `↑` / `↓` | Збільшити / зменшити кут нахилу поверхні |
| `←` / `→` | Зменшити / збільшити коефіцієнт тертя ($\mu$) |
| `1` | Схема перешкод №1 (розріджена) |
| `2` | Схема перешкод №2 (щільна група) |

## Вимоги до середовища

Для збирання та запуску проєкту необхідні:
- Компілятор з підтримкою **C++17** (MSVC, GCC, Clang)
- **CMake** (версії 3.20 або вище)
- **vcpkg** (встановлений та інтегрований із CMake через змінну середовища `VCPKG_ROOT`)
